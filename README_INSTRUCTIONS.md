# Instruções para publicar no GitHub

## PASSO A PASSO

1. Acesse github.com e faça login na conta.
2. Clique em New repository.
3. Nome do repositório: solar-museum (ou qualquer outro nome).
4. Marque como Public.
5. Clique em Create repository.

## SUBIR OS ARQUIVOS

1. Clique em Add files > Upload files.
2. Arraste para lá os seguintes arquivos:
   - index.html
   - assets/transicao-solar.mp4
   - assets/poster-solar.jpg
   - fotos (opcional)
3. Clique em Commit changes.

## VERIFICAR

1. Vá em Settings > Pages.
2. Em Branch selecione main.
3. Em Folder selecione /root.
4. Clique em Save.
5. Aguarde alguns segundos/minutos.
6. A URL será gerada: https://seunome.github.io/

## FINALIZAR

- Grave os links que aparecerem.
- Use essa URL como site oficial do SOLAR Museum.
