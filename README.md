# SOLAR Museum Site

Site estático pronto para hospedar no GitHub Pages.

## Estrutura

- `index.html` — página principal (hero em vídeo, narrativa exterior → interior)
- `assets/` — pasta para:
  - `transicao-solar.mp4` (seu vídeo)
  - `poster-solar.jpg` (capa/poster)
  - imagens das fotos reais do prédio

## Publicação no GitHub Pages

1. Criar novo repositório no GitHub.
2. Copiar todos os arquivos para o repositório.
3. Garantir que a página inicial seja `index.html`.
4. Ir em Settings > Pages.
5. Escolher Branch: `main` e pasta `/root`.
6. Salvar e aguardar a URL.

## Como usar

1. Abra `assets/` e coloque:
   - seu vídeo de transição como `transicao-solar.mp4`
   - sua imagem de poster como `poster-solar.jpg`
2. Abra `index.html` e troque os textos pelas versões finais.
3. Substitua as imagens temporárias da galeria pelas suas fotos reais.
